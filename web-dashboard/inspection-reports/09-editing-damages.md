# Editing damages and approving the estimate

On the web report you can change the repair method for a damage, apply discounts, and approve or reject the estimate. Every edit is recorded in the report's change log.

## Change a repair method

1. Open the report and go to the **Repair estimate** table.
2. Find the damage you want to change.
3. Click the **edit** (pencil) icon next to the **Repair Method**.
4. Select the new method.

## Apply a discount

Edit the **Discount %** for a line item. The **Discount** and **Final Price** columns update accordingly.

## Approve, reject or request customer approval

Each estimate row has an **Approve** checkbox. Below the table:

* **Approve** - approve the estimate.
* **Reject** - reject it.
* **Request customer approval** - send the estimate to the customer for approval.

Use the **Show clean panels** toggle to include or hide undamaged panels in the table.

## The change log

Every edit is recorded automatically in the report's change log, including the damage changes inspectors make during Damage Confirmation in the app. The change log appears below the checklist section on the report and is read-only. See [Understanding the report](08-understanding-the-report.md).
