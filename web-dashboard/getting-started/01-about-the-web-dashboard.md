# About the web dashboard

The ClearInspect web dashboard is the browser-based tool for JLR retailer staff. Open it in a desktop browser at [https://jlr-uat.web.app](https://jlr-uat.web.app) and sign in with your email and password, then confirm a one-time passcode (OTP).

## What you can do

* Invite customers to appraise their own vehicle using the ClearInspect Client app.
* Track the status of each invite and inspection.
* View completed inspection reports in full.
* Download and share reports as a PDF or by email.

{% hint style="info" %}
The web dashboard is for retailer staff only. Customers do not sign in here. They receive an invite by email and complete their appraisal using the Client app.
{% endhint %}

## The ClearInspect products

ClearInspect has three products that work together:

* **Web dashboard** (this guide): browser-based, for retailer staff.
* **Retailer app**: mobile app for retailer staff carrying out in-person inspections.
* **Client app**: for customers completing a self-appraisal after receiving an invite.

Retailer staff use the web dashboard to send invites and review reports. In-person inspections are carried out in the Retailer app. See [About ClearInspect](../../retailer-app/getting-started/01-about-clearinspect.md) for the Retailer app.
