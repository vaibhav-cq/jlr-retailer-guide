# Supported languages

The languages available in the ClearInspect Retailer app and Client app depend on your setup. Typical examples include:

* English
* English (US)
* German
* Spanish
* French
* French (Belgium)
* Dutch
* Dutch (Belgium)
* Italian
* Portuguese
* Romanian
* Slovak
* Slovenian
* Czech
* Greek

You can change the language from the hamburger menu on the home screen. The default language is selected based on your region. The language set for a customer invite defaults to the language chosen by the retailer when the invite is sent.

When you select a language, the app text updates straight away.
